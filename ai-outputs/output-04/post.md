### LinkedIn Post 28Jul26

Attached are 120 first draft machine readable diagrams based on an existing Phase 1 combined IND/IDE pancreatic cancer clinical trial protocol (a). Six open source diagram platform types (Mermaid, Excalidraw, PlantUML, D2, Diagrams (Python), and Graphviz) were adapted to LaTeX, outputted by AI as source code, and compiled once by the author using Overleaf. The purpose of the study was to achieve Mermaid-type diagram performance observed in several author studies, but now include five additional platforms, each with a different perspective on trial protocol data. 

All diagram code was generated in less than 2 hours using Claude Code Opus 5 Extra in a single session on the pro subscription. The significance of the study is that 1) A large number of machine readable diagrams from different viewpoints were generated based on existing trial protocol context, B) The first draft diagrams can be readily updated using an additional prompt or with manual editing, and C) Diagram code can be accurately understood by AI as inputs in future works, with comprehensive updates on the hour time scale. Note: the pdf DOI links reference to the original Phase 1 trial protocol. The prompt, source files, and README markdown are available on GitHub (b).
